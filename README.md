# 知行课堂作业管理系统

基于 Flask、Flask-Login、SQLAlchemy 和 SQLite，已完成规划中的第一、第二阶段：注册登录、课程管理、教学班与加入码、班级作业、截止时间、作业筛选、师生工作台，以及文件上传下载、评分和评语。

## 启动

```powershell
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
.\.venv\Scripts\python.exe app.py
```

已有 `.venv` 时直接执行 `.\.venv\Scripts\python.exe app.py`。浏览器打开 http://127.0.0.1:5000 。修改代码后需重启正在运行的旧进程。

数据库和 uploads 目录自动创建，重启后数据保留。默认没有预置账号。

## 第二阶段演示

1. 注册教师和学生账号，教师登录后进入工作台。
2. 教师在“课程管理”中创建课程，进入课程详情创建教学班，记录加入码。
3. 教师在“作业”页面展开“发布新作业”，选择对应课程和教学班，填写要求并设置未来的截止时间。
4. 学生登录后在“我的课程 / 加入班级”中输入加入码。加入前不能查看或提交该班级作业。
5. 学生通过关键词、课程、班级或状态筛选作业，在详情页上传文件。
6. 教师在工作台查看待批改任务，在作业详情查看班级提交进度、下载文件并评分；学生查看成绩与评语。

所有新增截止时间和提交时间统一使用北京时间。截止后禁止再次提交。未提交的任务显示“待提交”或“已逾期”；已提交的任务显示“已提交 · 待批改”或“已提交 · 已评分”。学生还可以按“已提交”统一筛选这两种状态。工作台提醒未来 3 天内到期且尚未提交的作业。

## 第一阶段数据升级

首次启动第二阶段代码时，会自动创建新增表并补齐旧表字段，不删除原账号、作业、文件和成绩。更改旧表之前自动生成 `homework.db.stage1.bak` 数据库备份。

历史作业按发布教师归入“第一阶段历史课程 / 第一阶段历史班级”，原提交学生自动加入相应班级；其他学生需通过加入码加入后才能查看。教师可以修改历史课程名称和简介，并在课程详情查看历史班级加入码。历史作业没有截止时间，继续保留原有行为；新发布的作业必须关联课程、教学班并设置未来的截止时间。重复启动不会重复生成历史课程或成员。

## 验证

```powershell
.\.venv\Scripts\python.exe -m unittest discover -s tests -v
```

测试使用独立的临时 SQLite 数据库与上传目录，不改动现有业务数据。覆盖迁移与备份、班级加入、师生权限隔离、作业发布校验、截止后禁止上传、状态与筛选、工作台、上传下载和评分流程。详细设计与验收说明见 [第二阶段开发说明](第二阶段开发说明.md)。

文件限制为 20 MB，支持常用文档、图片、代码、压缩包。教师仅能批改自己发布的作业，学生仅能下载自己的提交。

按照规划，Anaconda 环境配置留到系统全部完成后，经确认再进行，当前继续使用原有 `.venv`。

本项目为课程演示，注册页允许自行选择教师身份。公开部署应限制教师注册，设置 SECRET_KEY 环境变量，并使用正式 WSGI 服务和 HTTPS。
